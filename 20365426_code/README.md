Download src file, output files and test instances and store under the same project.
Copy and paste directory of file you would like as problem instance in CwRunner class under Problem problem = new Problem(" ").
Copy and paste directory of file you would like the output to be in CwRunner class under String filename = " ".
Adjust the number associated with the "long end" variable in CwRunner class to determine runtime of program i.e. 20000 = 20 seconds.
Adjust the max number of steps to determine how many iterations you would like each trial to run for.
If the trials finishes quicker than the time the user initially wanted, they will be shown how long the trial actually took.
Run the program under the CwRunner class as it stores the main method.
The output of the IDE for each iteration will be the best objective value and solution for each heuristic.
At the end you will see the total time taken, the fastest and slowest heuristic and also the heuristics with best and worst reinforcement learning score as the IDE output.
The best objective value and current value of each iteration will be displayed in the file selected by the user.
The best objective value and solution of each trial will be displayed in the file selected by the user.
The best heuristic will then be selected and displayed to the user as the output of the IDE.
